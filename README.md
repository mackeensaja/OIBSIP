# TravelEase – Travel Agency Landing Page

## 🌍 Project Overview

TravelEase is a modern and responsive travel agency landing page designed to inspire people to explore beautiful destinations around the world.

The website provides an attractive introduction to travel services, popular destinations, and the benefits of choosing TravelEase.

## 🎯 Project Objective

To create a visually appealing and user-friendly landing page using HTML5 and CSS3 as part of the Oasis Infobyte Web Development and Designing Internship – Level 1, Task 1.

## ✨ Features

- Modern and attractive navigation bar
- Hero section with headline and call-to-action button
- About TravelEase section
- Popular destinations section
- Why Choose Us section
- Footer with navigation and contact links
- Consistent blue and orange colour theme
- Responsive design for mobile and tablet screens
- Smooth scrolling navigation
- Attractive destination images

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts

## 🚀 How to Run the Project

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the project using Live Server.
5. Explore the TravelEase landing page in your browser.
