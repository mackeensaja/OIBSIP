# Tempora – Temperature Converter

## Project Overview
Tempora is a responsive temperature converter web application that converts temperature values between Celsius, Fahrenheit, and Kelvin.

## Features
- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Numeric input validation.
- Absolute zero validation.
- Display all three conversion results.
- Reset input and results.
- Responsive user interface.

## How to Run
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Enter a temperature value.
5. Select Celsius, Fahrenheit, or Kelvin.
6. Click the Convert Temperature button to view the results.

## Conversion Formulas

- Celsius to Fahrenheit: (°C × 9/5) + 32
- Fahrenheit to Celsius: (°F − 32) × 5/9
- Celsius to Kelvin: °C + 273.15

## Validation
The application prevents temperatures below absolute zero:
- Celsius: -273.15 °C
- Fahrenheit: -459.67 °F
- Kelvin: 0 K
